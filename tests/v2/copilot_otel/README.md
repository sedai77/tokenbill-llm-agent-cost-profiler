# tests/v2/copilot_otel — CP-OTEL acceptance tests

Package CP-OTEL (wave 2, GitHub Copilot): the single implementation that turns Copilot client spans
into canonical requests — VS Code first (its opt-in `agent-traces.db` and OTel JSON-lines outfile,
raw or as CP-VSCODE extracts), then managed OTel (OTLP/JSON; CLI and, behind flags, the CLI file
envelope and JetBrains), plus GitHub Agentic Workflows' `token-usage.jsonl`.

| module | registry name / API |
|---|---|
| `tokenbill/adapters/copilot_otel.py` | `CopilotOtelAdapter` (`copilot-otel`); the shared mapping `map_chat_spans(spans, opts, *, source, dialect)` over `SpanView` / `SpanEvent`; convention `github_copilot.otel` (registered on import); `sniff_copilot_otel`, `service_products`, `product_for`, `time_ms` |
| `tokenbill/adapters/copilot_vscode.py` | `VsCodeAgentTracesAdapter` (`copilot-vscode-traces`): read-only, allowlisted `agent-traces.db` and CP-VSCODE SQLite extracts |
| `tokenbill/adapters/gh_aw.py` | `GhAwTokenUsageAdapter` (`gh-aw-token-usage`); convention `gh_aw.token_usage` |

Run (from the worktree root): `PYTHONPATH=$PWD python -m pytest -q tests/v2/copilot_otel`.
Coverage: `python -m coverage run --source=tokenbill.adapters.copilot_otel,tokenbill.adapters.copilot_vscode,tokenbill.adapters.gh_aw -m pytest tests/v2/copilot_otel && python -m coverage report`
(96 % at hand-off). Fuzz: `TB_OTEL_FUZZ_EXAMPLES=300 … pytest tests/v2/copilot_otel/test_fuzz.py`
(40 examples per property by default; 300 ran clean at hand-off).

## Fixtures (`tests/v2/fixtures/copilot_otel/`)

Every fixture is **synthetic** (values invented; generated by `build_fixtures.py`, byte-stable).
The content canary is planted in every content attribute (`gen_ai.input.messages`,
`…output.messages`, `…system_instructions`, `…tool.definitions`, tool arguments / results,

names; `CANARY_LOGIN` in identity attributes.

## Design notes (interpretations)

- **Request keys**: `request_id_for("github", gen_ai.response.id, …)` when a response id exists
  (source independent, so the raw DB, an extract and an OTel dump of one call merge), else
  `stable_id("rq", "github_copilot", conversation, turn, span id)`. A key seen twice in one read
  counts once (`stats["duplicate_spans"]`).
- **Synthesized spans**: a chat span without a response id, with usage, not an error, from
  `copilot-chat` (or a VS Code DB row); skipped when its trace holds a native span (OTel files:
  `service.name = github-copilot`; DB rows: a chat span with a response id), else kept with
  `dq.copilot_synthesized_span_kept`.
- **Lanes**: MAIN by default; SUBAGENT when an explicit initiator / interaction value says so or the
  span has two or more `invoke_agent` ancestors (agent id = the nearest agent's `gen_ai.agent.id`,
  else its name, else its span id; the lane's parent is the main lane); HELPER for background
  interactions; COMPACTION for compaction interactions. Conversation id: the span's
  `gen_ai.conversation.id`, else the DB `chat_session_id`, else an ancestor's, else the trace id.
- **COST_STATE**: Σ nano-AIU of root `invoke_agent` spans (no `invoke_agent` ancestor) per
  conversation, on its main lane, at the latest root end; nested agents are never summed.
- **Context tier**: a stated tier attribute wins; else `copilot_chat.request.max_prompt_tokens`
  above the model's band threshold (`facts.copilot.band_rules`) → `long_context`, at or below →
  `default`; models without a band rule → unknown (None).
- **JetBrains**: a resource is JetBrains when its `service.name` is configured as
  `NAME=copilot_jetbrains`, or configured without a product and containing `jetbrains` / `intellij`
  (conservative: such resources need the flag). Unconfigured names are only Copilot through the
  scope / attribute-key predicate (then `copilot_other`).
- **Legacy CLI names** (`gen_ai.usage.cache_read_input_tokens`, `…cache_creation_input_tokens`):
  such chat spans are not requests; they are counted (with tokens) in
  `dq.copilot_legacy_otel_names`.
- **gh-aw**: `timestamp` is read as the completion time (`ts_start = timestamp − duration_ms`); the
  allowlisted `path` is kept as `Attribution.entrypoint`; source priority 20; repository / workflow
  names from `--attr` win over `GITHUB_REPOSITORY` / `GITHUB_WORKFLOW_REF` / `GITHUB_WORKFLOW`.
- `agent_product` follows the resource (`github-copilot` → `copilot_cli`, `copilot-chat` →
  `copilot_vscode`, others → `copilot_other`), never `--attr`.

## Unverified facts (VERIFY; shipped as documented fallbacks)

- The CLI OTel file envelope and CLI input inclusivity (flag `copilot-cli-otel-file`); pre-1.0.64
  underscore cache attribute names.
- JetBrains `service.name`, scope and attribute names (flag `copilot-jetbrains-otel`).
- The Copilot app's `service.name` (configured names map to `copilot_other`).
- Attribute names beyond the addendum allowlist: initiator / interaction type
  (`github.copilot.initiator`, `copilot_chat.initiator`, `…interaction_type`), context tier
  (`github.copilot.context_tier`, `copilot_chat.context_tier`), BYOK (`github.copilot.byok`,
  `copilot_chat.endpoint_type = byok`), TTFT (`copilot_chat.time_to_first_token`, ms), and the
  compaction / truncation span-event payloads (`trigger`, `pre_compaction_tokens`,
  `post_compaction_tokens`, `system_tokens`, `tool_definitions_tokens`, `duration_ms`,
  `tokens_removed`, camelCase variants accepted).
- The exact `otelSqliteStore.ts` DDL (column types, `tool_*` names, `span_events` layout) and the
  value encoding of `span_attributes.value` (numbers are accepted as integers or digit strings).
- gh-aw: the `_schema` value (`token-usage/…` prefix only is checked), the artifact name, and
  GitHub's verbatim five-line fixture (replace the synthetic stand-in at merge).
