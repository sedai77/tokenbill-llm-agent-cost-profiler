## Behaviour worth knowing (decisions the texts left open)

- **Inputs.** One file per `read` (plain or `.gz`); a directory is a `UsageError`. CSVs are read by
  header name (case-insensitive; BOM, quoting, CRLF, embedded commas); short rows are padded, long
  rows quarantined (`bad_type:row`). REST files: one response, a JSON array of responses, or
  CP-PULL envelopes `{"request": {path, query}, "response": {...}}` as a document or JSON lines.
- **Money.** Every amount goes through `core.money.usd_str_to_nano` once (float tails such as
  `0.4272621300000001` are exact); rows of one natural key are summed in exact integers and exact
  `Decimal` quantities. `stats["rounding_remainder_e18"]` is Σ remainders of the **net** amounts
  (the invoice side that `core.extensions.run_reconcilers` forwards under the adapter name, R-E44);
  `stats["rounding_remainder_e18.gross"]` holds the gross remainders (L1 diagnostic).
- **Natural ids.** AI usage report: `natural_id("cl", "github.ai_usage_report", date, principal,
  model_key, sku, organization, cost_center_name, repo_h)` where `model_key` is the normalized
  model, prefixed `auto:` for Auto rows and suffixed `:fast` for fast mode (the raw label, cleaned,
  for pseudo labels) — an Auto and a direct row of one model and user on one day are two lines
  (see CONTRACT-CHANGE-CP-BILL.md §1). Token aggregates: `natural_id("ag", …, date, "k=v"…)` over
  their sorted dims (the `core.builders.make_ai_usage_row` scheme). Metered lines: `(date,
  principal, sku, org, repo_h, cost_center_name, dynamic path or workflow h_, workload,
  cost_type)`; REST lines: `(cost_type, period, enterprise, org, principal, cost-center id,
  product, sku, model_key, unit, repo_h)`. Duplicates inside one file are summed
  (`dq.copilot_duplicate_key_summed`); across files the store keeps the latest `fetched_ms`.
- **People.** A non-empty `username` (REST: `user`) is mapped through `opts.team_map` /
  `opts.cost_center_map` (exact, then case-folded; a `cost_center_name` cell wins) and becomes
  `pseudonym(opts.principal_key, "p", login.strip())` — the raw login, case kept (SPEC §5.1
  `central-ingest`; CONTRACT-CHANGE §2). Without a principal key such a row raises `PrivacyError`.
  Repositories and agentic-workflow paths are `h_` under `opts.name_key` (required). Org logins
  (`[A-Za-z0-9][A-Za-z0-9._-]{0,63}`, else `bad_type:organization`) and cost-center names (control
  characters collapsed, clipped to 64 UTF-8 bytes — SPEC §8.1) stay clear; enterprise names enter
  natural keys only. Empty username →
  `principal=None`, `ai_credit.direct`, `dq.copilot_unattributed_rows`.
- **Tokens.** Stored under `github.ai_usage_report.excl` (input → uncached, `cache_write` →
  `cache_write_unknown`). A row with every token cell empty contributes no tokens and no aggregate
  (0 is not absent); legacy rows never carry tokens. The aggregate's `reported_cost_nano` /
  `list_cost_nano` are Σ net / gross of the rows that carried tokens (basis `invoice`).
- **Finality.** `final` iff the day (REST: the period's last day) is ≤ today − `report_lag_days`
  (facts, 3) **and** in a closed month; April 2026 rows are provisional forever
  (`dq.copilot_directional_report`). With the default `now_ms = 0` everything is provisional.
- **Legacy / preview.** `exceeds_quota` in the header, `unit_type == "requests"` or a
  `*_premium_request` SKU → `ai_credit.legacy_pru` (`dq.copilot_legacy_pru`). 2026-04-24…30 rows
  with quantity 0 and a non-zero numeric quota are dropped like GitHub's parser does
  (`stats["backfill_duplicates_dropped"]`; `Unknown` counts as 0 there). Non-zero `aic_*` cells on or
  after 2026-06-01 → `dq.copilot_preview_columns` (never read as money).
- **Plan quota** (`"copilot-report-quota" in opts.experimental`): per (month, org or `enterprise`,
  quota) one `ConfigSnapshot(kind="plan_quota", source_kind="github.ai_usage_report",
  snapshot_ms=<first instant of the month>, attrs month / quota (decimal string) / n_users)`;
  `n_users` counts distinct principals of that file — export whole calendar months (a month split
  over two files keeps the latest file's count). `Unknown`/empty → `stats["quota_unknown"]`, 0 →
  `stats["quota_zero"]`; legacy (PRU-quota) rows and rows without a username are never evidence.
  Without the flag: no snapshot, `dq.copilot_report_quota_ignored` counts rows with a usable quota.
  `core.pool.detect_plans` reads the rows (tested: 60 × 3900 + 5 unknown → seats
  `{enterprise: 60, unknown: 5}`, source `report_quota`).
- **Metered CSV.** Channel by product: `copilot`, `spark`, `code_quality` → `github_copilot`;
  `actions` → `github_actions`; `sandbox` → `github_sandbox`; others counted
  (`rows_other_products`). Actions rows are kept only for a Copilot workload of
  `core.catalog.copilot_workload` (the three dynamic paths, `.github/workflows/*.lock.yml` →
  `agentic_workflow` with `workflow = h_(path)`); other workflow paths are counted
  (`user_workflows_dropped`), rows without a path too (`actions_unattributed_dropped`, e.g. every
  Actions row of a summarized report); paths are never stored. AI-credit and premium-request SKUs
  → `metered.ai_credit` (a cross-check, never a cell); seat SKUs → `seat` with the SKU kept for
  `detect_plans`; Actions discounts kept (`list_amount_nano` = gross).
- **REST.** `ai_credit/usage` and `premium_request/usage` → `rest.ai_credit`, `usage/summary` →
  `rest.summary`, `usage` → `rest.usage`; the endpoint comes from the envelope path, else the
  shape. Date = first day of the `timePeriod` (year / month / day grain). The `usage` endpoint's
  integer `quantity` of AI-credit SKUs is dropped (`dq.copilot_integer_quantity`); report-export
  envelopes (`usage_report_exports`, `report_type` + `status`/`download_urls`, or a `/reports` path)
  yield nothing (`stats["export_envelopes"]`) and no URL is ever read into a record.
- **Conventions.** `excl`: input → uncached. `incl`: uncached = input − read − write; a row with
  read + write > input cannot be inclusive and is mapped exclusively with `dq.convention_mismatch`
  (`core.pool.build_cells` clamps at 0 instead; the reconciler decides per file, §12).
- **Capabilities.** `cost`, `aggregates`, `copilot_billing` as present; `config` only when plan-quota
  snapshots are emitted (declared maximum of `github-ai-usage` includes it). No request, session,
  lane or inference is ever emitted, so ruling R-E43 has nothing to set.
