# CP-RATES tests — GitHub Copilot rate data, YAML verifier, golden cases

Package CP-RATES (wave 2b) owns `tokenbill/copilot/rates_verify.py`,
`tokenbill/copilot/data/{__init__.py,github_copilot.json,snapshots/**}`, this directory and
`tests/v2/fixtures/copilot_rates/**`. Binding text: CP-RATES brief, CORE-AMENDMENTS C-28 / K-3 / A-1,
addendum §6, §19.2, §19.5, Appendix C.G, SPEC §6.1–§6.3, §6.7, §6.9, Appendix E (R-E19, R-E34).

## What ships

- `github_copilot.json` (`tokenbill/rates@1`, provider `github`, channel `github_copilot`): 55 rows
  and 3 modifiers (`github.auto` ×0.9, `github.compliance` ×1.1, both `stacking: assumed`;
  `github.fast.opus-4-8` `replace_base` $10/$50). The 46 rows of `facts.copilot.rates` are
  reproduced byte for byte; 9 further rows are the closed intervals of models the table no longer
  lists (ruling R-E34: GPT-4.1, GPT-5.2, GPT-5.2-Codex, Gemini 2.5 Pro, Gemini 3 Flash, Gemini
  3.1 Pro ×2, Raptor mini, MAI-Code-1-Flash).
- `snapshots/models-and-pricing-2026-09-22.json` (`tokenbill/copilot-pricing-snapshot@1`): the
  recorded parse (maps of strings) of revision `2026-09-22_d1153b57c9`, compared at 2026-09-22.
- `rates_verify.py`: YAML mini-parser (`parse_yaml_list`), normalization (`quotes_from_maps`),
  `load_revisions` / `replay`, the loader with SPEC §6.1 validation (`load_layer`,
  `layer_from_json`), and `verify(layer, *, snapshot=None, live=False, opener=None)`
  (`EXTENSIONS["copilot"].rate_verifier`). Price, threshold, band, missing / unlisted row and
  fast-mode discrepancies are authoritative; category, promotion footnote, alias and disabled-row
  findings are warnings. Claude rows' 1-hour write is never compared (unpublished, DC6).

Both data files are generated by `build_rate_file.py` from the fixtures; `test_rate_file.py`
asserts byte equality. To add a revision: copy `<YYYY-MM-DD>_<sha10>.yml` and its `commits.txt`
line into the fixtures, run
`uv run --python 3.12 python -m tests.v2.copilot_rates.build_rate_file --write`, review the diff,
and record changes that facts must follow for the next contract window (`facts.copilot.rates`).

## Fixtures and provenance

`tests/v2/fixtures/copilot_rates/yml/`: the 38 dated revisions of
`github/docs:data/tables/copilot/models-and-pricing.yml` (2026-04-27 → 2026-09-22; public GitHub
documentation data, no personal data) plus `commits.txt` (ISO commit timestamp and full SHA per
line), copied unchanged from the research inputs `copilot/raw/yml/` (RULINGS G-2, CORE-AMENDMENTS
O-4). Every other YAML in the tests is synthetic. No transcripts, no content, no credentials.

## Known limitations

- `Modifier` has no effective dates, so `github.fast.opus-4-8` prices fast-mode usage at any date,
  although the table lists fast mode only from 2026-06-29; `verify` against revisions before that
  date reports it (`test_verify.py` expects exactly that). See `CONTRACT-CHANGE-CP-RATES-1.md`.
- Claude Sonnet 5 carried a promotion footnote 2026-06-30 → 08-11 with unchanged prices; its row
  has no promotion id, so `verify` on those revisions gives a non-authoritative `promotion` warning.
- The gate tests assume RATES' PLAN API (`rates.schema.load_builtin`, `load_file`,
  `rates.engine.RateCard(layers)`); they were exercised once against a scratch stand-in only.
